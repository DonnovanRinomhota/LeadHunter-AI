# Workflow 03 — outreach draft generation

1. Trigger only for a qualified lead with an eligible recommendation.
2. Confirm no opt-out / suppression event exists.
3. Generate a short, contextual draft using only verified source details and approved SpiritusTec positioning.
4. Store draft with status `pending`.
5. Notify internal reviewers with a secure dashboard link.
6. Wait for human decision in the application.

The workflow ends at draft creation. It must not send prospect-facing messages.
